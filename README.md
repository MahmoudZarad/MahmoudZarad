## 🧩 Featured Projects

### 🛒 E-Commerce Web API

Production-grade E-Commerce backend built with a focus on scalability, security, and maintainability.

- Clean Architecture, DDD, and CQRS
- JWT authentication with refresh token rotation
- RBAC and policy-based authorization
- Redis caching and server-side pagination
- Stripe payments and webhook validation
- Hangfire background processing
- xUnit and Moq testing
- Serilog structured logging
- API versioning and global exception handling

🔗 **Repository:**  
https://github.com/MahmoudZarad/Ecommerce

🌐 **Live API:**  
https://mahmoudstore.runasp.net/swagger

---

### 💸 ExpenseTracker

Full-stack personal finance platform for managing income, expenses, budgets, and financial insights.

- Angular frontend with reusable components and reactive forms
- ASP.NET Core Web API backend
- JWT authentication and authorization
- User-specific financial data isolation
- Transactions, categories, and budget management
- Dashboard with financial statistics and charts
- Pagination, validation, and business rules
- Clean Architecture and CQRS
- Repository Pattern and Unit of Work
- Docker Compose with Nginx and SQL Server

🌐 **Live Application:**  
https://expensetracker.hoodaabdo665.workers.dev

📚 **API / Swagger:**  
https://expensetracker3.runasp.net/swagger/index.html

🔗 **Repository:**  
https://github.com/MahmoudZarad/ExpenseTracker

---

### 🚗 DVLD Management System

Enterprise-style desktop application for managing driving licenses and vehicle department workflows.

- Structured 3-Layer Architecture
- Centralized Business Layer
- License issuance, renewal, replacement, detention, and release
- Test scheduling and application workflows
- ADO.NET data access layer
- Parameterized SQL queries and transactions
- Multi-entity lifecycle management
- Windows Event Log for auditing and monitoring
- SOLID principles and modular design

🔗 **Repository:**  
https://github.com/MahmoudZarad/DVLD-Management-System
